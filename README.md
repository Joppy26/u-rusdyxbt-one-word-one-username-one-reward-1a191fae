Entry for the [make.fun bounty](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae): one word, one username, one reward.

## Entry

`calm-meteor-20` — my own make.fun username, sent as a single word.

## How it works

`main.ts` writes the fixed text `calm-meteor-20` to `/output/entry.txt`.
It is fully deterministic: same output on every run, no input, no randomness,
no network, no external tools.

Run it with Node 22 or later:

```sh
node main.ts
```
